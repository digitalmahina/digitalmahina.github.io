# Смысловое поле — этап 1: разметка пакета

Скрипт `fap/scripts/kg_build.py` (без зависимостей, ~3 с на всю базу) читает `fap/data/docs/*.json`
и пишет `fap/data/kg/<id>.json` + `fap/data/kg/index.json` (manifest со статистикой).
Всё правилами, источник каждой связи `src: "rule"`; модели здесь нет.

## Что в пакете документа
- `mode`: `pt` (пункты 2.19.2) или `art` (статьи — Воздушный кодекс).
- `points[]`: `n`, `part` (0 — сам приказ, 1 — утверждённые правила, 2… — приложения; 1.01 — новый блок нумерации),
  `ch` (глава), `sec` (раздел без номера, напр. «Бортовые приборы и оборудование»), `text` (дословно, переносы строк внутри абзаца склеены).
- `spans[]`: `{s,e,t}` — смещения в `text`. `t`: `zapret`, `iskl`, `dopusk`, `usl`, `ref`. Номер пункта во фрагмент не входит;
  в «За исключением …, запрещается …» исключение и запрет — два разных фрагмента.
- `refs[]`: `{s,e,to,kind,type,ctx:[s,e],src}`.
  - `kind`: `point`, `range` (не раскрывается), `chap`, `art`, `doc` (документ целиком).
  - `to`: `{doc,p}` / `{doc,range}` / `{doc,ch}` / `{doc,art[,p]}` — в базе; `{ext,label}` — вне базы (id вида `20051121-139`).
  - `type`: `iskl`, `usl`, `srok`, `dop`, `raschet`, `red` (служебная пометка о редакции — в UI скрывать), `gen`.
  - `ctx` — границы предложения/клаузы вокруг ссылки (вместо обрывка ~96 символов).
  - `ok: 1` — цель найдена в базе.
- `back[]`: кто ссылается на пункт `{doc,p,type}` — по всей базе, включая межд документами.
- `defs[]`: `{term, def[, p]}` — термины и дословные определения.

## Известные ограничения
- ФАП‑21 (`20190727-184`) нумерован по-европейски (21.16B) — пункты пока не режутся.
- Типы связей по правилам: для исключений recall важнее precision, возможны ложные «исключения».
- Таблицы ФАП‑258 пока не разбираются.
- Цепочки 5.56 → 5.57 → 5.59 строятся из `refs` на клиенте, не в пакете.
